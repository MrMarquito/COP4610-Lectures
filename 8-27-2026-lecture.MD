# Three Pillars of OS 
Virtualization, Persistance, and Concurrence

### Definitions ###
1. Bare-metal code refers to software that runs directly on computer hardware without an operating system or any runtime.
2. Time-sharing: OS switches a single physical resource among multiple tasks, giving each task the illusion of dedicated access to that resource. KEY CONCEPT
3. Virtualization: OS abstracts physical resources into virtual resources, giving each program the illusion of having dedicated access tot that resource.
4. Space Partitioning: OS divides a single physical resource into multipe isolated portions. KEY CONCEPT
5. Memory Virtualization: OS avstracts physical memory into isolated virutal address spaces, giving each program the illusion of having dedicated access to a complete cpu.
6. Persistance: OS maganes long-term data storage by virtualizing storage devices into file systems, ensuring data remains available after a program terminates or the system loses power.
7. File system: virtualizes storage devices into a hirearchical structure of files and directories, providing programs with a simple interface to store, organize, and retrieve persistent data.
8. Locking: mechanism that ensures only one taks can acess a shared resource at a time, preventing conflicts from interleaved execution.
9. Synchronization:  set of techniques that coordinate the execution of multiple tasks, ensuring they access shared resources in a correct and predictable order.
10. Cocurrence: OS coordinates multiple simultaneously executing tasks to ensure they share resources correctly without conflict.
